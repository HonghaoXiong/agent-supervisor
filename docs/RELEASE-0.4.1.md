# 0.4.1 — 原生固定会话与多通道

- 新增 ZCode 官方扩展投递：向用户指定的空闲桌面会话追加轮次，GUI 保留同一会话记录。
- 新增具名通道：分别绑定 Codex chat、ZCode session、socket、令牌、投递账本和收据目录，支持并发及增量加载。
- 保留默认 legacy 路由；未知通道与 owner 不符时拒绝，不切换到其他会话。
- 每轮校验合同与真实持久消息。重复恢复不重发，原子发布收据且不覆盖首次证据。
- 发行包增加原生扩展、ZCode 本地市场元数据及注册/投递入口；所有包与 manifest 版本统一为 0.4.1。

使用方法见 [原生通道说明](NATIVE-CHANNELS.md)。Codex 安装仍使用 `Install.command`；ZCode 原生功能需安装包内同一插件，正常授予 `sessions.write` 并重载扩展。目标须先在桌面加载并取得完成锚点，工具审批模式不变。

真实并发验收限 macOS / ZCode 0.17.1、extension API 1.4.0 的两个专用桌面会话；不同 Codex owner 的拒绝由离线回归和真实配置检查覆盖。本轮不扩大为两个独立 Codex chat 的自动回投实测、其他桌面平台或 OS 沙箱资格。

离线验证：Python 33 项、Node 27 项、发行完整性/确定性/可迁移性检查 10 项通过。本次发布整理未调用真实模型或改动现用业务通道。
